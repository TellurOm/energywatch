sensors About Demo Simulation

EnergyWatch is running on realistic simulated energy telemetry.

No physical electricity meter, smart plug, or IoT sensor is connected to this device. The application is architected with a decoupled data layer (EnergyDataSource) so a real smart meter or utility API can seamlessly replace this demo data without rewriting UI components.

bolt Active Power Measurement

Active Power (kW) represents the instantaneous rate of electricity demand of active appliances in your household.

In this prototype, readings fluctuate realistically between 1.70 kW and 2.15 kW based on simulated appliance cycling.

When deployed with an IoT smart meter (such as an ESP32 ADE7758 / PZEM-004T current transformer clamp), this card displays real-time hardware sensor data.
